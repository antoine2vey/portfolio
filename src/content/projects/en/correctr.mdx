---
summary: "Correctr is a Chrome extension that fixes grammar and spelling directly in the selected text, powered by GPT-4o. Select text on any web page, right-click, and the text is replaced with its corrected version. No copy-pasting, no switching tabs."
---

The architecture is a lightweight Hono server that relays requests to the OpenAI API, plus a Chrome Manifest V3 extension with a service worker and a content script. Everything is written in strict TypeScript, with Effect for typed error handling and dependency injection.
